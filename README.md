# Mini Coffee App

A simple app for coffee lovers to explore, order, and manage coffee products across web and mobile platforms.

## Technologies Used
- **Backend:** Spring Boot  
- **Web Frontend:** ReactJS + Vite  
- **Mobile App:** Kotlin

## Steps to Run the Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
2. Build the project (using Maven or Gradle):
    ./mvnw clean install 
3. Run the Spring Boot application:
    ./mvnw spring-boot:run

## Steps to Run the Frontend
1. Install dependencies:
    npm install
2. Start the development server:
    npm run dev

## Steps to Run the Mobile App
1. Open the Kotlin project in Android Studio.
2. Connect an Android device or start an emulator.
3. Build and run the app from Android Studio (\`Run > Run 'app'\`).
4. The app should launch on your device/emulator.
